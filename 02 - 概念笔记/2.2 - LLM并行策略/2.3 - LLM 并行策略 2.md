# 2.3 - LLM 并行策略

## 概述

大型语言模型（LLM）的训练和部署面临巨大的计算和内存挑战。为了克服这些瓶颈，需要采用各种并行策略。本笔记将深入探讨几种关键的并行策略，包括张量并行（TP）、序列并行（SP）和流水线并行（PP），以及它们如何协同工作以优化资源利用。

*   **相关概念**:
    *   Megatron-LM 中的 Ring-Allreduce (ringcp) 与 Ulysses 中的 Ring-Allreduce (ulysses cp) 的比较。
    *   MoE (Mixture of Experts) 系列模型。

## 一、张量并行 (Tensor Parallelism, TP)

张量并行旨在将单个 Transformer 层的计算和激活值分散到多个 GPU 上，以减少单个 GPU 的内存占用。

TP is intra-layer 就是层内并行。

### 1.1 基本符号说明

在讨论并行策略时，我们使用以下符号：

-   $s$: 序列长度 (sequence length)
-   $b$: Batch size
-   $h$: Hidden size (隐藏维度)
-   $a$: 注意力头数 (attention heads)
-   $t$: 张量并行大小 (tensor parallel size)，表示将一层切分到 $t$ 个 GPU 上。
-   $p$: 流水线并行大小 (pipeline parallel size) - *注：在当前公式中未直接使用，但作为并行策略的一部分。*

### 1.2 激活内存公式：不并行 (单卡 / DDP)

在不进行张量并行的情况下（例如，单卡训练或使用数据并行 DDP），每层的激活内存占用公式为：

$Activations\ memory\ per\ layer = sbh(34 + 5\frac{as}{h})$

**公式拆解：**

-   $sbh$: 这是序列长度 $\times$ batch size $\times$ hidden dim，代表激活张量的**元素总数** (shape 为 $s \times b \times h$)。
-   $34$: 来自多个激活项的固定系数，例如 Q、K、V 投影、输出投影、MLP 中间状态、LayerNorm 输入输出等。
-   $5\frac{as}{h}$: 注意力机制的二次项。
    -   $a$ 个头，每个头有 $s \times s$ 的注意力分数矩阵。
    -   当转换为每个元素 ($sbh$) 的系数时，会得到 $5\frac{as}{h}$。

> **注意：** 当序列长度 $s$ 很大时，二次项 $5\frac{as}{h}$ 占主导地位，这是导致长序列激活内存爆炸的主要原因。

### 1.3 激活内存公式：张量并行 (TP)

当采用张量并行时，每个 Transformer 层的矩阵乘法被切分到 $t$ 个 GPU 上。因此，一些中间激活也会被切分，显存占用会分摊到 $t$ 张卡上。

$Activations\ memory\ per\ layer = sbh(10 + \frac{24}{t} + 5\frac{as}{ht})$

**各项含义：**

1.  **$10sbh$** (与 $t$ 无关的部分):
    -   LayerNorm (4 $sbh$)
    -   Dropout (2 $sbh$)
    -   输入到 Attention 和 MLP 的激活 (4 $sbh$)
    -   这些激活在张量并行中**依然在每个 GPU 完整保留**，因为 LayerNorm / Dropout 等操作通常需要全局激活信息。
2.  **$\frac{24}{t}sbh$**:
    -   来自 Attention 和 MLP 中的中间激活。这部分激活在张量并行后可以除以 $t$ 进行分摊。
3.  **$5\frac{as}{ht}sbh$**:
    -   注意力二次项的系数。由于每个 TP 组只负责部分注意力头，这部分内存也除以 $t$。

### 1.4 对比：张量并行效果分析

| 情况 | 激活内存公式 | 特点 |
|---|---|---|
| 无并行 | $sbh(34 + 5\frac{as}{h})$ | 二次项 $5\frac{as}{h}$ 影响大，长序列时内存占用巨大。 |
| 仅张量并行 | $sbh(10 + \frac{24}{t} + 5\frac{as}{ht})$ | 大幅降低二次项，但固定项 $10sbh$ 仍随 $s, b, h$ 线性增长，成为新的瓶颈。 |

**直观例子：**
如果 $t=8$，二次项几乎降低 8 倍。但固定项 $10sbh$ 依然随 $s, b, h$ 线性增长。
> 图中指出 “looking pretty good, but not quite there” —— 张量并行有帮助，但 LayerNorm / Dropout 这些未并行的激活仍会成为大模型瓶颈。

### 1.5 与 Flash Attention 的关系

第一张图提到：
> As with flash attention, we can drop this term via recomputation

-   公式中的 $5\frac{as}{h}$ 二次项主要来自于**存储注意力分数矩阵** ($a \times s \times s$)。
-   如果使用 **Flash Attention**，就不需要存储完整的 $s \times s$ 注意力矩阵，可以在反向传播时重新计算。
-   因此，这部分内存可以“去掉”。

**去掉二次项后：**

-   **无并行 (用 Flash Attention)** $\approx sbh \cdot 34$
-   **张量并行 (用 Flash Attention)** $\approx sbh(10 + \frac{24}{t})$

这更接近当前大模型训练的实际做法，Flash Attention 显著缓解了长序列的内存压力。

## 二、序列并行 (Sequence Parallelism, SP)

即使使用张量并行 (TP)，仍然存在一个与 $t$ 无关的 $10sbh$ 项，这部分内存无法通过 TP 降低。这 $10sbh$ 来自于 LayerNorm (4 $sbh$)、Dropout (2 $sbh$) 以及输入到 Attention 和 MLP 的激活 (4 $sbh$)。这些是**沿序列维度的逐点操作 (pointwise ops over the sequence)**，在原始 TP 中并没有被切分。

### 2.1 核心思路

序列并行的核心思想是：**把 LayerNorm / Dropout 这类沿序列维度的操作也切分到不同 GPU 上。**

图中 Transformer 层结构里标出的 **g** 操作：

-   **g (All-Gather)**: 前向时，把切分的序列拼回完整序列（用于 Attention / MLP 等需要全局信息的操作）。
-   **g (Reduce-Scatter)**: 前向时，把计算结果再切分回去。

反向传播时，这两个操作顺序相反。

**效果：**
原来每个 GPU 存储完整的 $s \times b \times h$ 的 LayerNorm 输入/输出，现在只存储 $\frac{s}{t} \times b \times h$（假设切分序列维度）。所以 $10sbh$ 项也除以 $t$。

### 2.2 激活内存公式对比表 (结合 TP, SP, 重计算)

| 配置 | 每层激活内存 |
|---|---|
| 无并行 | $sbh(34 + 5\frac{as}{h})$ |
| 仅张量并行 (TP) | $sbh(10 + \frac{24}{t} + 5\frac{as}{ht})$ |
| **张量 + 序列并行 (TP + SP)** | $sbh(\frac{34}{t} + 5\frac{as}{ht})$ |
| 张量并行 + 选择性重计算 (TP + Recompute) | $sbh(10 + \frac{24}{t})$ |
| **张量 + 序列 + 选择性重计算 (TP + SP + Recompute)** | $sbh(\frac{34}{t})$ |

**逐行解释：**

1.  **无并行**: 基准情况，二次项 $5\frac{as}{h}$ 很大。
2.  **仅 TP**: $10sbh$ 项不随 $t$ 变化，成为瓶颈。
3.  **TP + SP**: $34sbh$ (原来的 $10sbh + 24sbh$) 都除以 $t$ 了，二次项 $5\frac{as}{ht}$ 仍存在。
4.  **TP + 选择性重计算**: 丢掉二次项，但 $10sbh$ 项还在。
5.  **TP + SP + 选择性重计算**: **完美线性扩展**，只剩下 $sbh \cdot \frac{34}{t}$。

### 2.3 选择性重计算 (Selective Recomputation)

-   **描述**: 不存储所有中间激活值，而是在反向传播时重新计算某些层的前向结果。
-   **作用**: 能够去掉二次项 $5\frac{as}{h}$ (即注意力分数矩阵的存储)。
-   **代价**: 增加约 30–50% 的重计算时间。

### 2.4 结论：激活内存的线性扩展

通过结合**张量并行 (TP)**、**序列并行 (SP)** 和**选择性重计算 (Selective Recomputation)**，可以实现激活内存的完美线性扩展：

$Activations\ memory\ per\ layer = sbh \cdot \frac{34}{t}$

这意味着**每增加一倍 GPU ( $t$ 翻倍)，激活内存占用减半**。这是当前大模型训练（如 Megatron-LM）实现超长序列或超大模型的关键技术组合。

## 三、流水线并行 (Pipeline Parallelism, PP)

流水线并行是将模型的不同层分配到不同的 GPU 上，形成一个计算流水线。

### 3.1 优势

1.  **更节省内存，相比 FSDP (Fully Sharded Data Parallel)**: PP 只需要在 GPU 之间传递激活值，而不是完整的模型参数或梯度，因此内存开销相对较小。
2.  **通信效率更高**: 通信量主要取决于激活值的大小，并且通常是点对点 (point-to-point) 通信，而不是集合通信。这使得 PP 在通信带宽较低或延迟较高的环境中表现良好。

### 3.2 TP 在推理时的加速

*   **问题**: 为什么张量并行 (TP) 在推理时也能带来加速？
*   **简答**: 在推理时，TP 同样将模型的参数和计算分散到多个 GPU 上。虽然推理通常不需要存储梯度和中间激活，但对于非常大的模型，单个 GPU 可能无法容纳完整的模型参数。TP 允许模型参数跨 GPU 分片存储，并且每个 GPU 只计算模型的一部分，从而加速单个请求的处理时间，并允许部署更大的模型。
