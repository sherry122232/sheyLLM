# Transformer

> [!note]
> 基于 self-attention 的序列建模架构，由 Vaswani 等人于 2017 年提出（"Attention Is All You Need"）。它摒弃了 RNN/CNN 的递归或卷积结构，完全依赖注意力机制捕捉序列中的依赖关系，成为现代大语言模型的统一基础架构。当前主流 LLM（GPT、LLaMA、Qwen、DeepSeek 等）均基于 Transformer 的 Decoder-only 变体。

---

## 核心组件

Transformer = tokenizer + position embedding + transformer block * layers + linear + softmax 

一个 Transformer 层由两个主要子层组成：

| 子层 | 作用 | 计算 |
|------|------|------|
| **Multi-Head Self-Attention** | 让每个位置关注序列中其他位置，建模 token 之间的依赖关系 | $\text{Attention}(Q,K,V) = \text{softmax}(QK^T / \sqrt{d}) V$ |
| **Feed-Forward Network (FFN)** | 对每个位置独立做非线性变换，提供表达能力 | $\text{FFN}(x) = \text{Activation}(xW_1 + b_1)W_2 + b_2$ |

每个子层后接残差连接和 Layer Norm：

$$\text{Output} = \text{LN}(x + \text{SubLayer}(x))$$

### 位置编码

> [!note]
> Transformer 中为 token 序列注入位置信息的机制。因为 self-attention 本身是排列不变的（permutation invariant），模型无法从纯内容 embedding 中区分"第 1 个词"和"第 10 个词"，必须通过额外手段注入顺序信号。主流方案分为绝对位置编码和相对位置编码两大类，其中 **RoPE 是当前 LLM 最核心的方案**（LLaMA、Qwen、DeepSeek 等均采用）。

---

#### 一、绝对位置编码

##### 1.1 可学习位置编码（Learned PE）

给第 $0, 1, 2, \ldots$ 个位置各分配一个可训练向量，加到 token embedding 上。做法和词向量类似，模型自己学每个位置的表示。

优点是简单直接；缺点是对超出训练长度的序列泛化较差——模型没见过的位置编号没有对应的嵌入向量。

##### 1.2 正弦余弦位置编码（Sinusoidal PE）

原始 Transformer 论文（Vaswani et al., 2017）提出的方法。用不同频率的 sin/cos 函数构造每个位置的向量：

$$PE_{(pos, 2i)} = \sin(pos / 10000^{2i/d}), \quad PE_{(pos, 2i+1)} = \cos(pos / 10000^{2i/d})$$

不需要学习参数，且对更长序列有一定外推能力（因为三角函数的周期性提供了某种连续性）；但灵活性不如可学习方法。

---

#### 二、相对位置编码

相对位置编码不再强调"当前位置是第几位"，而是强调"两个 token 相距多远"。这更符合注意力的本质——注意力本来就在比较 token 两两之间的关系。

##### 2.1 Relative Position Bias

直接给 attention logits 加一个与相对距离有关的偏置项。距离越近偏置越大，距离越远偏置越小或为零。T5 等模型中很常见。

实现简单，适合长序列；但表达能力有限，偏置项通常是查表或分桶得到。

##### 2.2 ALiBi（Attention with Linear Biases）

在 attention 分数上加一个与相对距离成**线性关系**的 bias：

$$b_{ij} = -\alpha \cdot |i - j|$$

参数少、实现轻量、长文本外推能力不错；但表达能力通常不如 RoPE 细腻。

##### 2.3 RoPE（Rotary Position Embedding）

当前最主流的位置编码方案。它不是把位置向量加到 embedding 上，而是把 Query 和 Key 的每一对维度做**旋转**，让位置关系自然体现在点积里。

对第 $i$ 个频率通道，RoPE 的角频率为 $\omega_i = b^{-2i/d}$，位置 $p$ 的旋转角为：

$$\theta_i(p) = p \cdot \omega_i = p \cdot b^{-2i/d}$$

其中 $b$ 是 base（常见默认值 $10^4$），$d$ 是 head 维度。不同维度用不同频率随位置旋转，相位差进入 $q,k$ 内积后就把相对位置信息编码进了 attention score。

**为什么 RoPE 主流？** 它能很好地表达相对位置信息，并且和注意力机制结合得自然——改的是 Q/K 本身而非 attention logits，因此与各种 attention 变体（MHA/GQA/MLA 等）兼容性好。

---

#### 三、RoPE 的长上下文扩展

标准 RoPE 在训练长度内效果很好，但如果直接把上下文硬拉到超出训练范围，会出现高频分量变化过快、位置相位分布失真、远距离 attention 衰减等问题。以下方法用于缓解这些问题：

##### 3.1 YaRN（Yet another RoPE extensioN）

**改进位置编码缩放**。核心思路是不粗暴地统一压缩所有位置，而是更平滑地重映射 RoPE 的位置尺度：

$$p \mapsto g(p)$$

即把原始位置 $p$ 通过一个温和的映射函数变成新位置，再送入 RoPE。近距离部分尽量少动保住原有能力，远距离部分逐渐压缩让超长位置落进可处理范围。

可以理解为一种"分段、稳定"的 RoPE scaling——比简单线性缩放更不容易出现性能崩塌。

##### 3.2 DCA（推理期注意力修正）

**解决的问题是**：即使训练时做了长上下文扩展，推理阶段随着上下文继续拉长，RoPE 仍可能导致 attention 分数系统性失真——越远的位置越不易被正确关注，模型偏向近邻 token。

DCA 在推理时修正这种现象，本质上是**把"绝对位置直接做差"的相对位置矩阵替换成"按块分段重编号后再做差"的矩阵**。效果有两个：
- 超长上下文下相对位置不再越界，避免未见过的超大距离上失真
- 相邻块之间加了 successive-chunk 修正，不完全牺牲局部连续性

##### 3.3 ABF（Adaptive Base Frequency）

不改 RoPE 基本形式，只改 **base $b$**，让旋转角增长得更慢：

$$\theta_i(p) = p \cdot b^{-2i/d}, \quad b \gg 10000$$

例如 Qwen2.5 将 base 从 $10^4$ 提高到 $10^6$，后续更长阶段继续提高到 $10^7$。数学效果：

$$b \uparrow \Rightarrow \omega_i \downarrow \Rightarrow \theta_i(p) \text{ 增长更慢}$$

高频旋转变慢、远距离衰减减轻、上下文可外推到更长范围。"Adaptive" 指的是为某个长上下文阶段选更大的 base，不是每个 token 实时自适应。

##### 3.4 四者的定位对比

| 方法   | 改的是什么                                 | 层面      |
| ---- | ------------------------------------- | ------- |
| YaRN | 位置映射 $p \mapsto g(p)$                 | 训练 + 推理 |
| DCA  | 推理时的注意力分数修正                           | 仅推理     |
| ABF  | 频率 $\omega_i = b^{-2i/d}$ 中的 base $b$ | 训练      |

三者常配合使用。**长上下文能力 = 训练期长度扩展 + 推理期位置/注意力外推修正**，不是单靠训练堆出来的。

---

#### 四、其他变体

- **xPos**：在 RoPE 基础上引入指数衰减的位置权重，改善长程衰减特性
- **LongRoPE**：通过大幅扩大 RoPE 的 base 并重新初始化位置嵌入来实现超长上下文
- **二维位置编码**：Vision Transformer 中使用，同时编码行和列位置（图像是二维网格）

---

#### 五、学习优先级

如果从大语言模型角度学习，推荐路径：

$$\text{sin/cos} \to \text{learned PE} \to \text{relative bias} \to \mathbf{RoPE} \to \text{ALiBi} \to \text{YaRN / DCA / ABF}$$

一个值得记住的关键区分：**RoPE 改的是 Q/K 本身，Relative Bias / ALiBi 改的是 attention logits**。

> [!warning]
> - 位置编码的选择会影响模型的外推能力，但不影响短序列内的表现——同一模型换不同的位置编码方案，在训练长度内效果差异通常不大
> - YaRN / DCA / ABF 不是新的主体架构，而是"让 RoPE 模型在比训练时更长的序列上仍然可用"的技术，属于 RoPE 生态的扩展
> - 二维位置编码只在 Vision Transformer 等非序列场景中使用，NLP 任务中不涉及

### Attention

> [!note]
> Transformer 的核心计算机制。通过 Query-Key-Value 三元组计算序列中任意两个位置之间的相关性权重，再对 Value 做加权求和，实现信息聚合。标准 self-attention 公式：$\text{Attention}(Q,K,V) = \text{softmax}(QK^T / \sqrt{d}) V$。它是 Transformer 替代 RNN/CNN 的关键创新——任意位置之间一跳直达，路径长度 $O(1)$。

---

#### 标准形式

给定输入 $X \in \mathbb{R}^{S \times D}$：

$$Q = XW_Q, \quad K = XW_K, \quad V = XW_V$$

$$\text{Attention}(Q,K,V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d}}\right) V$$

Multi-Head Attention 将 $D$ 维拆成 $H$ 个头并行计算，每个头学习不同的注意力模式，最后拼接输出。

#### 变体谱系

##### MQA

Multi-Query Attention 的做法很直接——Q 保持多头不变，K 和 V 压缩到只有 1 份：

$$Q \in \mathbb{R}^{B \times H \times S \times d}, \qquad K, V \in \mathbb{R}^{B \times 1 \times S \times d}$$

所有头共享同一组 K 和 V 来计算注意力分数。KV Cache 直接缩减为原来的 $1/H$。

代价也很明确：不同头无法学习差异化的注意力模式，表示多样性下降。实际效果通常略低于完整 MHA，尤其在需要复杂表示的任务上。
**架构对比**：

```
标准 MHA:                    MQA:
Q: [h, d]                    Q: [h, d]
K: [h, d]                    K: [1, d]     ← 共享！
V: [h, d]                    V: [1, d]     ← 共享！

```

|                |   MHA   |     GQA      |    MQA    |
| :------------: | :-----: | :----------: | :-------: |
| KV 头数 $H_{kv}$ |   $H$   | $G$（$1<G<H$） |     1     |
|  KV Cache 大小   |   基准    |   约 $G/H$    |  约 $1/H$  |
|      表达能力      |   最强    |    接近 MHA    |    较弱     |
|      推理速度      |   基准    |    接近 MQA    |    最快     |
|      代表模型      | 多数预训练模型 |  LLaMA-2/3   | PaLM, GLM |

> [!warning]
> - MQA/GQA 减少的是 **KV Cache 的存储**，不是 attention 计算量本身——Q 仍然是多头的，attention score 矩阵大小不变
> - "GQA 效果等于 MHA" 是近似说法，复杂任务上仍有可测量的差距
> - 选择 $G$ 值时需要在效果和速度之间权衡，没有万能最优值
---

##### GQA
GQA（Grouped-Query Attention）可以看作是 **MHA 和 MQA 之间的折中方案**。

它的核心思想是：**每个注意力头仍然保留独立的 Query，但 Key 和 Value 不再是每个头各自一份，而是把多个头分组，每组共享一份 K/V。**

设 batch size 为 $B$、序列长度为 $S$、query 头数为 $H$、kv 头数为 $G$、单头维度为 $d$（总隐藏维度 $D = H \cdot d$），则：

$$Q \in \mathbb{R}^{B \times H \times S \times d}, \qquad K, V \in \mathbb{R}^{B \times G \times S \times d}$$

其中 $1 < G < H$。Q 仍然是完整的多头结构，而 K/V 的头数被压缩成了 $G$ 个。每个 kv head 会服务一组 query heads，因此叫做 Grouped-Query Attention。
##### MLA

| 方案 | 压缩策略 | 本质 |
|------|---------|------|
| MHA | 不压缩 | 每头独立 K/V，表达能力最强 |
| MQA | 减少 KV 头数 | 所有头共享 1 份 K/V |
| GQA | 减少 KV 头数 | 按 $g$ 组共享 K/V |
| **MLA** | **低维 latent 压缩** | K/V 经低秩瓶颈压缩后缓存 |

MQA/GQA 通过减少 KV 的**份数**来压缩；MLA 则把每份 KV 本身的**维度**压低，走的是不同的压缩路径。
######  核心机制：低维 Latent 压缩

标准 Attention 中，对隐藏状态 $h_t \in \mathbb{R}^d$：

$$q_t = W_Q h_t, \quad k_t = W_K h_t, \quad v_t = W_V h_t$$

MLA 不直接缓存 $k_t, v_t$，而是先经下投影压缩到低维空间：

$$c_t^{KV} = W_{DKV} h_t$$

$c_t^{KV}$ 就是缓存的对象——一个远小于原始 K/V 维度的 latent 向量。需要参与注意力时，再通过上投影恢复：

$$k_t^C = W_{UK} c_t^{KV}, \quad v_t^C = W_{UV} c_t^{KV}$$

合起来看，这相当于给原始 K/V 投影加了一个低秩瓶颈：

$$k_t^C = W_{UK} W_{DKV} h_t, \quad v_t^C = W_{UV} W_{DKV} h_t$$

"恢复"不是精确逆变换，而是可学习的近似解码——只要恢复出的表示对注意力计算足够有用即可。

Q 同样经过低维 latent 通道：

$$c_t^Q = W_{DQ} h_t, \quad q_t^C = W_{UQ} c_t^Q$$

但 Q 压缩的目的不是减少缓存（Query 只服务于当前时刻，不需要跨时间缓存），而是形成统一的低秩参数化结构，配合后续的 RoPE 解耦和矩阵吸收。**KV 压缩才是 MLA 的核心收益来源。**
##### 稀疏注意力

> [!note]
> 通过约束注意力连接范围来降低计算和显存成本的方案族。标准 self-attention 是稠密连接（$O(S^2)$），稀疏注意力只保留部分有价值的连接，将复杂度降到近似线性。局部注意力和滑动窗口注意力是其中最常见的形式。

标准 attention 中，序列长度为 $S$ 时每个 token 要与全部 $S$ 个 token 计算相关性，attention 矩阵大小 $S \times S$，计算复杂度 $O(S^2)$。上下文越长，这个代价越不可接受。

核心思路很直接：**不让每个 token 看全部位置，只看最有价值的一部分**。

$$\text{滑动窗口 Attention} \subset \text{局部 Attention} \subset \text{稀疏 Attention}$$

- **稀疏注意力**是最一般的框架：任意"只保留部分连接"的 attention 模式
- **局部注意力**是特例：只允许关注附近邻域
- **滑动窗口注意力**是局部注意力最典型的实现：固定大小的连续窗口沿序列滑动

###### 局部注意力

设窗口半径为 $w$，第 $i$ 个位置的可见邻域：

$$\mathcal{N}(i) = \{j \mid i - w \le j \le i\}$$

（因果模型中只看左侧，双向模型中两侧都看）

远离当前位置的 token 被 mask 为 $-\infty$，不参与 softmax。复杂度从 $O(S^2)$ 降到 $O(Sw)$。

局限在于单层无法直接捕获远距离依赖——信息需要靠多层堆叠逐步传播，和卷积网络中小感受野多层叠加后扩大感受野的原理一样。

###### 滑动窗口注意力

窗口长度为 $w$ 时，第 $i$ 个 token 只看 $[i-w+1,\, i]$ 范围内的 token。随着 $i$ 前进，窗口同步滑动。

举例（$w=4$）：
- token 5 → 看 2,3,4,5
- token 6 → 看 3,4,5,6
- token 7 → 看 4,5,6,7

结构规整、易于工程实现，适合与 causal mask 结合。Mistral 等模型在部分层中使用滑动窗口注意力来平衡效果和效率。

###### 更一般的稀疏模式

除了局部窗口外，还有几种常见设计：

| 模式 | 做法 | 目的 |
|------|------|------|
| 局部稀疏 | 只看附近固定窗口 | 降低基础计算量 |
| 跳跃式稀疏 | 额外允许每隔固定间隔采样远处 token | 以较小代价接触远距离信息 |
| 全局 + 局部 | 特殊 token 充当全局信息中转站 | 弥补局部窗口无法跨远距通信的问题 |
| 块稀疏 | 序列分块，只允许部分块之间互相 attention | 规整结构，便于硬件并行 |

###### 复杂度与感受野

| 方案 | 复杂度 | 远距离依赖 |
|------|--------|-----------|
| 全 attention | $O(S^2)$ | 一跳直达 |
| 局部 / 滑动窗口 | $O(Sw)$ | 多层传播 |
| 设计良好的稀疏 attention | $O(Sw)$ ~ $O(S \log S)$ | 少量远程连接辅助 |

一个关键点：**局部注意力不等于模型永远看不到远处信息**。一层只能看左右各 $w$ 个 token，但多层堆叠后等效感受野会不断扩大。全 attention 的优势是远程依赖可以一跳直达；局部/稀疏方案的优势是用低得多的代价覆盖大部分实际需求——很多任务中局部依赖本身就占主导地位。

> [!warning]
> - 理论复杂度下降不一定转化为实际的同比加速——稀疏操作在 GPU 上未必比稠密矩阵乘法更快
> - 稀疏模式设计不当会损害信息流动，效果损失可能超过预期
> - "长上下文"问题不能仅靠稀疏注意力解决，通常需要配合 KV Cache 压缩等其他技术

> [!warning]
> - "Attention" 有时指整个机制族（含所有变体），有时特指标准 scaled dot-product attention，需根据上下文区分
> - 复杂度 $O(S^2)$ 指的是标准稠密 attention；稀疏变体可降到 $O(Sw)$ 或更低
> - $\sqrt{d}$ 缩放因子防止点积值过大导致 softmax 饱和（来自原始论文）

## 两种主要结构

### Encoder–Decoder

传统 Transformer 的完整结构，用于翻译、摘要等 seq2seq 任务。

**Encoder**：由多层 self-attention + FFN 组成，$Q, K, V$ 均来自输入序列本身，负责将输入编码为包含全局语义的表示。

**Decoder**：由三层组成：
- **Masked Self-Attention**：$Q, K, V$ 来自 decoder 输入，加 causal mask 使每个位置只能看到自己和之前的 token
- **Cross-Attention**：$Q$ 来自 Decoder，$K, V$ 来自 Encoder 输出，让 Decoder 在生成时读取输入信息
- **FFN**

核心作用：**先理解输入，再条件化地生成输出**。适合输入和输出边界清晰的任务。

### Decoder-only

现代大语言模型最主流的结构。去掉 Encoder 和 cross-attention，只保留带因果掩码的 self-attention 与 FFN，通过自回归方式完成生成。

每层的 $Q, K, V$ 都来自当前层输入，加 causal mask 后每个位置只能访问自身及之前的 token。训练目标通常是 next-token prediction——给定前文预测下一个 token。

核心优势：把各种任务统一为"给定前缀，继续生成后文"，结构简单、扩展性强、适合开放式文本生成、对话和代码生成。GPT 系列、LLaMA、Qwen、DeepSeek 均采用此结构。

### 两者对比

| | Encoder–Decoder | Decoder-only |
|--|-----------------|--------------|
| 注意力类型 | Self-attn + Cross-attn | Masked self-attn |
| 典型任务 | 翻译、摘要等 seq2seq | 通用文本生成 |
| 信息流 | 输入 → 编码 → 条件解码 | 前缀 → 自回归续写 |
| 结构复杂度 | 较高（双塔 + 交叉注意力） | 低（单塔） |
| 主流程度 | 特定领域仍使用 | 当前 LLM 绝对主流 |

## 为什么 Transformer 取代了 RNN

| 维度 | RNN/LSTM | Transformer |
|------|----------|-------------|
| 长距离依赖 | 需逐步传播，梯度消失/爆炸 | 任意位置之间直接 attention，一跳直达 |
| 并行化 | 序列步骤串行，无法并行 | 所有位置同时计算 |
| 路径长度 | $O(N)$ | $O(1)$（任意两点间） |
| 固定表示 | 整个序列压缩到一个状态 | 每个位置保留独立上下文化表示 |

Transformer 的 $O(1)$ 路径长度是其成功的关键理论优势——信息在两层之间可以直接从任意位置传到任意另一位置，不受序列长度影响。

---

> [!warning]
> - Decoder-only 不是"去掉了 Encoder 的功能"——它通过足够的层数和自回归机制同样能学习到强大的表示能力
> - Pre-LN（Layer Norm 在 sublayer 之前）比 Post-LN 训练更稳定，是现代实现的主流选择
