## 1. 一条主线

LLM 可以先看成一条从输入到上线的链路：

```text
文本 / 图像 / 工具请求
  -> 输入表示与模型结构
  -> 预训练形成基座能力
  -> 后训练与对齐塑造行为
  -> 参数高效微调适配场景
  -> 推理优化支撑服务
  -> 线上反馈推动迭代

训练系统工程横切所有阶段。
```
